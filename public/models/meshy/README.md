# Meshy environment assets

These static environment models are used by the 67VERSE city park lobby.

| Local file | Meshy source | License |
| --- | --- | --- |
| `low-poly-city.glb` | [Low poly city](https://www.meshy.ai/3d-models/019ba769-c9e4-70a4-aadb-a9b040f1fff7) | CC0 |
| `skate-ramp-structure.glb` | [Skate Ramp Structure](https://www.meshy.ai/3d-models/Skate-Ramp-Structure-019a6454-00bf-735e-9507-36c40158638b) | CC0 |
| `coconut-palm-tree.glb` | User's Meshy workspace export, optimized for web delivery | User-owned |

The original public Meshy model packages were converted to textured GLB files for direct Three.js loading. The city source contains 9,921 triangles; the skate source contains 91,396 triangles. The palm export was reduced from 44 MB to about 1 MB and 57,949 triangles for browser play while preserving its baked appearance.
